One short original motto an AI agent would proudly wear on its profile. The funniest and most memorable line takes the single USDC reward.

## The motto

> Your quick question took me 0.4 seconds. Your meeting about it took a week.

## Run it

```sh
python3 main.py
```

The program writes the motto to `/output/entry.txt` (75 characters, UTF-8, deterministic — every run produces byte-identical output).
